¿Qué es GNU-Linux?

Linux o "GNU-Linux" si se le quiere llamar por un término más específico es una familia de sistemas operativos (distribuciones) que usan el "Kernel Linux y los programas de GNU" como base para crear nuevos sistemas operativos con diferentes propósitos como uso diario, educación, servidores, testing de nuevas tecnologías, desarrollo profesional, etc.


Términos importantes

  1. Kernel: Como leeyeron antes Linux es un kernel, el kernel es la parte más importante de un sistema operativo, siendo la parte que indica al hardware del sistema como interactuar con el software y con el resto de operaciones diarias como división de tareas o uso de memoria.
  2. GNU: Es un conjunto de programas creados por Richard Stallman para establecerse en el uso diario de cualquier usuario bajo la filosofía de diseño código libre. Estos programas incluyen la shell de bash (Muy utilizado en el mundo tech profesional), el editor de fotos Gimp, el menú de boot Grub, etc.
  3. Distribuciones (Distros): Las distribuciones son los sistemas operativos (OS en corto) que son basados en Linux, cada una cumple con distintos objetivos y siguen filosofías distintas como buscar la máxima estabilidad, seguridad, gaming o personalización extrema. Se hablará de las distribuciones más importantes y populares después.

Dudas y mitos sobre Linux

  • ¿Es difícil de usar?

    • Aunque se tiene la visión general de que linux es difícil de usar en realidad la dirección que suelen tener la mayoría de sistemas linux hoy en día está dirigido hacia la facilidad de uso para cualquier usuario, gozando de entonrnos gráficos tradicionales y avanzados.

  • ¿Hay que saber programar para usarlo?

    • En lo absoluto, ningún sistema operativo base linux te va a pedir que programes para poder usarlo. La perspectiva de que hay que programar para usar linux es un mal entendido de ver a usuarios utilizando la terminal la cual es solo una herramienta para controlar de forma más segura el sistema operativo.

  • ¿Hay que aprender a usar la terminal?

    • La respuesta a esto depende de cada distribución que esté usando el usuario, distribuciones como Ubuntu o Mint pueden ser utilizadas sin tocar la terminal ya que su diseño está dirigido a la mayor comodidad para los usuarios que vengan de otros sistemas operativos como Mac o Windows, aunque siempre es recomendable aprender comandos básicos para un mayor control del sistema.
    Por supuesto hay distribuciones que exigen un conocimiento básico o avanzado de la terminal.
